Figma frame (SVG)

How to use

1. Open your Figma file.
2. Drag and drop `figma-frame.svg` into the canvas — Figma will import it as vector layers.
3. Ungroup the imported SVG if you want to convert parts into Figma Styles (Colors / Text Styles / Effects).
4. Map colors to your Tokens Studio or Figma Tokens plugin by selecting shapes and assigning Color Styles.

Notes
- The SVG uses hex values matching the design tokens (background `#1A1A1A`, accent `#7FA650`, CTA `#81B64C`).
- After import you can replace text fonts with the exact Google fonts in Figma (Montserrat, Open Sans, Roboto Mono).
